# 팀 대시보드

연구실 보고서와 그림을 찾아보고, 팀 파일을 주고받고, 메모와 날짜별 작업 기록을 남기는 대시보드입니다. 설치 직후에는 모든 목록이 비어 있습니다.

## 시작

Python 3.10 이상에서 실행합니다. 별도 패키지는 필요하지 않습니다.

```sh
python3 server.py
```

브라우저에서 `http://localhost:8810/`을 엽니다. 이미 8810 포트를 쓰고 있다면 `--port 8811`로 실행합니다. `--data /path/to/team-data`로 저장 폴더를 지정할 수 있습니다. 기본 저장 폴더는 저장소 안의 `data/`입니다. 별도 경로를 쓰는 경우에도 운영 데이터를 Git에 추가하지 마세요.

- 보고서 탭은 저장 폴더의 `reports/`에 넣은 HTML, PDF, Markdown, 텍스트 파일을 표시합니다. HTML은 리소스를 내장한 단독 파일을 사용합니다.
- 그림 탭은 `figures/`에 넣은 이미지와 PDF를 표시합니다.
- 파일 탭에서 업로드한 파일은 `files/`에 저장됩니다. 기본 업로드 한도는 파일당 100 MiB입니다. `--max-upload-mib`로 바꿀 수 있습니다.
- 메모와 기록은 `entries.sqlite3`에 저장됩니다. 기록은 날짜와 제목, 본문을 입력해 추가합니다.

## 팀 서버에서 실행

서버는 루프백 주소에서 실행됩니다. 팀에 한 주소로 공유하려면 내부 HTTPS 리버스 프록시와 팀 인증을 앞에 둡니다. 프록시에서 페이지와 API 모두에 인증을 적용하고, 외부 Host 헤더를 유지한다면 `--host dashboard.example.org`로 해당 값을 허용합니다. 전용 서비스 계정으로 실행하고 저장 폴더는 운영 서버에 둡니다. 이 앱에는 사용자 계정과 역할 관리가 없으므로 접속한 팀원은 같은 메모, 기록, 파일을 이용합니다.
